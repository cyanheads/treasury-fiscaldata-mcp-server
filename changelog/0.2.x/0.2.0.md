# 0.2.0 — 2026-10-03

## Added

- **`treasury_dataframe_drop`** deletes one tenant's staged table and provenance. Enable it with `TREASURY_DATAFRAME_DROP_ENABLED=true` and `CANVAS_PROVIDER_TYPE=duckdb`; the disabled definition retains an HTTP landing-page enable hint.

## Changed

- **Error recovery** uses automatic contract hints from the framework; wire errors also inherit request IDs and field-level argument repairs from the framework upgrade.
- **Build and dependency checks** use TypeScript declarations plus Bun's Node-compatible ESM bundler and Knip, with package dependencies external ([#27](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/27)).
- **Docker** cross-installs target bindings on the native build host, installs OpenTelemetry peers at framework ranges, and removes unused musl packages.
- **Packaging and docs** expose the drop flag in MCPB and both plugins, exclude bundles from npm, sync framework scripts/skills and CodeQL categories, and document opt-in failed-call payload logging and OTLP log export.

## Fixed

- **`CANVAS_TTL_MS`** treats blanks and whole-value placeholders as unset while preserving millisecond conversion and the 60-second minimum; malformed values fail startup with the environment variable's name ([#25](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/25)).
- **Registry launches** invoke the npm bin directly and fix `MCP_TRANSPORT_TYPE=http` for the HTTP package entry.
