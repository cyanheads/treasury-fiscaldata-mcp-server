# 0.1.11 — 2026-09-20

## Changed

- **`@cyanheads/mcp-ts-core` ^0.12.3 → ^0.13.6** — thirteen framework releases. The skill tree moves from `skills/` to `framework-skills/` so a plugin install no longer hands development skills to every installing agent; `src/index.ts` now declares `sessionMode: 'stateless'` explicitly rather than relying on `MCP_SESSION_MODE`'s schema default.
- **`.github/workflows/codeql.yml`** — the one GitHub Actions workflow this server carries, added by the framework scaffold.
- **README restructured** around an Overview opener and a per-tool capability reference, matching the framework's current template shape.

## Fixed

- **`treasury_dataframe_query`'s Markdown table formatter escapes backslashes ahead of pipes** ([#23](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/23)) — a cell escaped `|` as `\|` but left the value's own backslashes untouched, so a client's Markdown renderer consumed them: `x\|y` rendered as `x|y`, `a\*b` as `a*b`. `structuredContent` was unaffected.

## Security

- **CodeQL `js/incomplete-sanitization` #1** (high) — the same backslash-then-pipe fix above; an agent reading `content[]` could silently lose characters from a Treasury column value carrying a backslash.
