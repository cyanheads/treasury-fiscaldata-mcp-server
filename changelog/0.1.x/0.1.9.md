# 0.1.9 — 2026-08-13

## Changed

- **`treasury_get_interest_rates`'s empty-result span probes are gated on a date range having been sent, not on `mode === 'series'`.** A series request with neither `start_date` nor `end_date` already ran the same unbounded `security_desc` filter in its main fetch and matched nothing, so the probe would only repeat that empty answer — that path now skips straight to naming the current month's security types. Notice text is byte-identical in every other case; only the two upstream probe requests are skipped.
- **`scripts/verify-catalog.ts` imports `BASE_URL` from `fiscal-data-service.ts`** instead of duplicating the constant.
