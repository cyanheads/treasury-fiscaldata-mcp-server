# 0.1.8 — 2026-08-13

## Added

- **`bun run verify:catalog`** ([#22](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/22)). Probes every `datasets.ts` entry and diffs its field names against the endpoint's `meta.labels`, failing on a path that does not answer or a field it does not have. Network-bound, so it stays out of `devcheck` and the test suite; the diff logic is tested offline.

## Changed

- **`treasury_get_interest_rates` empty-result guidance is read off the data** ([#20](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/20)). A `mode=series` miss reports the type's record count and date span, unbounded by the requested range; otherwise the notice names the types the most recent month carries.
- **Catalog field lists mirror each endpoint's full field set** ([#22](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/22)) — 133 names to 288. `treasury_offset_program` (42 fields) and `auctions_query` (114) carry a curated subset and say so in their descriptions.

## Fixed

- **`security_type` accepts any string, matched exactly against `security_desc`** ([#20](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/20)). The closed enum of 8 rejected live values such as `Federal Financing Bank` and the savings and government account series; a blank value means no filter.
- **Eight catalog endpoints returned HTTP 404** ([#22](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/22)). Six were a swapped `/v1/`–`/v2/` prefix; `auction_results` became `auctions_query`, `top/top_state` became `treasury_offset_program`, and Securities Outstanding points at `/v1/debt/mspd/mspd_table_1`, which carries the public/intragovernmental split the entry describes.
- **29 catalog field names did not exist upstream** ([#22](https://github.com/cyanheads/treasury-fiscaldata-mcp-server/issues/22)) — `high_rate`, `open_mon_bal`, `parent_desc`, `item_desc`, and the rest — and failed any `treasury_query_dataset` call that passed them. Entry descriptions were reconciled against the live data in the same pass.
