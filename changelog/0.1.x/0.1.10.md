# 0.1.10 — 2026-08-25

The wire-level changes below arrive with `@cyanheads/mcp-ts-core` `^0.11.5` → `^0.12.3` and its MCP SDK v2 migration.

## Added

- **`tests/tools/wire-contract.test.ts`** pins the three properties the framework decides for every tool: input objects are strict, `error` is declared on neither `output` nor `enrichment`, and `structuredContent` and `content[]` carry the same information on success, on enrichment, and on a declared failure. 236 → 268 tests.

## Changed

- **HTTP endpoints serve protocol revision `2026-07-28` alongside the 2025 revisions.** Which one a connection gets is still negotiated at `initialize`.
- **Advertised JSON Schema is 2020-12, not draft-07.** A strict 2020-12 client no longer rejects a tool before dispatching it.
- **Tool input roots advertise `additionalProperties: false` and reject an undeclared argument by name.** A key the schema does not declare used to be stripped and the call ran anyway; it is now a validation error naming the key.
- **The advertised `outputSchema` declares the `error` envelope.** A client that validates `structuredContent` without first checking `isError` stops rejecting error results with `-32602`.
- **The server advertises `logging` and `resources: { subscribe: true }`,** and `ctx.log` output now also reaches the client as `notifications/message` at the level `logging/setLevel` sets.
- **`treasury_query_dataset`'s `filters[]` element objects are strict.** Root-level strictness does not reach a nested object, and a stripped key inside a filter is a narrowing the caller believes they set — an undeclared key there is now rejected by name rather than dropped.
- **`.env.example` sets `MCP_SESSION_MODE=stateless`** and documents `MCP_HTTP_RESUMABILITY` with its `_MAX_EVENTS` / `_TTL_MS` bounds — a stateful-only SSE replay buffer, inert while serving stateless.
- **Bun pins move to `1.4.0`** — both `Dockerfile` stages and `packageManager`. `engines.bun` stays `>=1.3.0`. The build stage is pinned to `$BUILDPLATFORM`, since Bun 1.4.0 aborts compiling under QEMU and the multi-arch image's `linux/amd64` leg builds there.
- **`CLAUDE.md` / `AGENTS.md` and the shipped `skills/` tree re-synced to the framework** — the removed task surface is gone and `ctx.elicit` is replaced by `ctx.requestInput` / `ctx.inputs`.
- **`scripts/lint-mcp.ts` drops its task-handler branch, and `scripts/lint-packaging.ts` treats `@modelcontextprotocol/server/dist/` as the critical runtime path** in place of `@modelcontextprotocol/sdk/dist/`.
