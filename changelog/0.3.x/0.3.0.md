# 0.3.0 — 2026-10-25

## Changed

- **DataCanvas** defaults to `duckdb` in npm and Docker installs; set `CANVAS_PROVIDER_TYPE=none` to disable staging and SQL.
- **SQL columns named current_schema must be table-qualified, such as t.current_schema; unqualified references are rejected.**
- **Framework validation** repairs numeric strings and optional `null` inputs before validation; invalid framework counts and timers fail startup with the environment variable's name.
- **Framework responses** escape Markdown in error and enrichment text, bound validation issue lists with explicit counts, and settle cancelled calls as `RequestCancelled`.
- **Framework logging** generates request IDs, records client IDs as `jsonRpcId`, redacts credential-bearing URL paths, and keeps underlying causes in logs rather than client errors.
- **Desktop MCPB** disables DataCanvas and removes its canvas/drop settings because the portable bundle omits native DuckDB bindings; use npm, Docker, or the hosted endpoint for SQL.
- **Tooling and docs** sync framework checks and guidance, correct client connection examples, and give Docker writable cache directories.

## Fixed

- **Node startup** loads `.env` before resolving the canvas default and opt-in dataframe drop flag, preserving explicit `none` and reporting invalid configuration through the startup banner.
- **Treasury request logs** identify the endpoint without copying query parameters.
- **MCPB contents** exclude source, tests, tooling, and coverage artifacts.
